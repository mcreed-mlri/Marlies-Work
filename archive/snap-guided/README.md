# Archived guided ending

The guided version of the SNAP work rules screener, where pick-list answers compose
the statement to DTA instead of blank write-in boxes.

Archived 2026-08-03. The team is not pursuing this ending for now; the shipping
screener at `masslegalhelp/tool/snap/index.html` is write-in only.

Unlike the other files under `archive/`, this page loads the live
`masslegalhelp/snap-screening-logic.js` module rather than a frozen copy, so
composed sentences stay in sync with the logic tests and copy documents. The HTML
and routing here are not maintained as a second build.

Open from the preview site at `/archive/snap-guided/`, or from the screener home
under "Archived guided ending."
