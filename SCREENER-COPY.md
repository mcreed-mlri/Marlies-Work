# SNAP ABAWD screener: all copy

Every word the screener shows, in the order someone answering the questions meets
it. Generated from the code, so it is what the tool actually says today, not a
description of it.

**How to edit this.** Change the text under any heading. Leave the `code.name` in
backticks alone: that is how each piece of text is found in the code, and it is the
only thing keeping your edit from landing in the wrong place. Add a comment anywhere
you want to; nothing here has to stay tidy.

Places where an earlier edit was unclear are marked **Question for you**. Those are
the ones holding up the rest of the work.

Legal accuracy is not settled here. The income and hour thresholds below were last
checked in November 2025, and the MLRI ABAWD article on MassLegalHelp was reviewed in
February 2026, so the article is newer than the tool. Someone has to reconcile the two.

(`masslegalhelp/index.html`) and the shared decision logic. If a string is on the page,
it should be in here; if you spot something missing, that is a bug in the generator and
